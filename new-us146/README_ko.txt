V4 제3세력 146명 이미지 복구 결과

등록·검증: 144명 이미지 파일, CDN HTTP 200 재다운로드 및 SHA-256 동일성 확인 완료.
원본 이미지 143명과 메이의 동일 파일 미리보기 1명을 구별한다.
미확보: US098 블랙파이어, US119 울트라 휴머나이트.
추가 원본 필요: US085 오버로드는 섬광으로 인물 식별 곤란, US152 메이는 동일 이미지의 250px 미리보기만 복구.
배경 인물 또는 설정화가 있는 11명은 등록부에 단독 크롭 검수 필요로 표시했다.
사용자의 초상 승인, 파일 저장, CDN 검증, 단독·판본 검수, Android 앱 표시 성공은 서로 별개다.
146명 전원의 공식 초상 적격 또는 소설 헌법 검수 완료를 뜻하지 않는다.

V4_US146_offline_gallery.html을 열면 images 폴더의 실제 파일을 오프라인으로 볼 수 있다.
V4_US146_gallery.html은 실제 검증한 CDN 주소를 사용한다.
CSV는 이름별 파일 경로·CDN URL·해시·주의사항을 제공한다.
JSON 등록부와 검증 기록은 다운로드 결과와 오류 원인을 보존한다.

CDN 오류 원인: 기존 저장소의 배포 패키지 50MB 한도 초과 응답을 확인했다.
기존 main은 보존하고, 약 14.7MB의 us146-cdn 배포 브랜치를 분리하여 해결했다.
검증하지 않은 대체 이미지나 추측 URL은 공식 등록부에 추가하지 않았다.
