# Korean crossover portrait source registry

39 selected portrait files, added on 2026-11-24 at the user's request. Existing cdn/, new-149/, new-15/ and images/ portraits are preserved.

- 21 selections were isolated as rectangles from official Naver Webtoon panels. No face redrawing or generative replacement was used.
- 18 selections are reposted artwork: 9 author-profile reposts and 9 original-cut reposts. Their original publication locator remains unverified and is explicitly recorded; they are not presented as fully verified official portrait approvals.
- portrait_registry.json records names, work, original page and asset URLs, original dimensions, crop rectangles, stored dimensions, SHA-256, Git blob SHA and tested display URLs.
- Image-file registration is separate from approval of characters, combat values, skill conditions and voice cards. No new active V4 roster entries are implied by this directory.
- validation.json records successful HTTP download, image decoding and byte-hash comparisons. KR023 uses the tested commit-pinned jsDelivr URL because the main-branch URL returned HTTP 403 during verification.
